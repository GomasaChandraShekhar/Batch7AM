var: The var keyword declares a variable with a function or global scope and allows re-declaration and updates 
     within the same scope.

let: The let keyword declares a variable with block scope, which allows updates but not re-declaration within 
     the same block.

const: The const keyword declares block-scoped variables that cannot be reassigned after their initial 
        assignment.

Scope of Variable ::

Function Scope
Global Scope
Re-declaring Variables
No Block Scope

Function Scope :: Declared inside the function.

function demo(){  
    var a = 20;       
    console.log(a);  
}  
console.log(a); //output: ReferenceError: a is not defined 


Global Scope :: Declare a variable outside of a function, it creates a global variable that can be accessible
                anywhere throughout the program.

var global = "Hello JavaScript";  
console.log(global);  

Re-declaring Variables :: We can re-declare variables in the same scope without facing any errors, 
                          which may lead to some unintended behavior.

var name = "Gomasa";  
var name = "Chandra";  
console.log(name);  

No Block Scope :: In JavaScript, unlike let and const, var keyword does not have block scope, which means that 
                  when you declare a variable using var inside a block is accessible outside that block.

Async Arrow Function
In JavaScript, you can make the arrow function asynchronous by using the async keyword before the parameter list.

const fetchData = async () => {  
  try {  
    const response = await fetch('https://rickandmortyapi.com/api/character');  
    const data = await response.json();  
    console.log(data);  
    return data  
  } catch (error) {  
    console.error('Error fetching data:', error);  
  }  
};  
fetchData();

Synchronous :: 

Execution Flow: Code is executed line by line, in a strict, sequential order.

Blocking Nature: Each operation must complete before the next one can begin. If a task takes a 
                 long time, it will "block" the entire program, making the application unresponsive.

Simplicity: It is generally easier to write, read, and debug due to its predictable, linear flow.



Asynchronous :: 

Execution Flow: Allows multiple tasks to run concurrently using Web API requests.

Non-Blocking Nature: The program remains responsive. A time-consuming operation runs in the 
                     background, and the program is notified via a callback or promise when the 
                     result is ready.


JavaScript Promises :: 

A promise in JavaScript is an object that is used to represent the eventual completion or failure 
of an asynchronous operation. 

With the help of Promise in JavaScript, users can handle asynchronous operations in a more 
manageable and readable manner.

States of Promise :: 

Pending: It is the initial phase, which represents that the asynchronous operations are still in 
          progress.

Fulfilled: It indicates that the asynchronous operation has been completed successfully.

Rejected: It indicates that the operation has failed.

async/await: Used with function declaration to implement waiting for
 each statement to complete the execution.

Async/Await is used to write asynchronous code in a clean, synchronous-like manner, making it easier
 to read, understand, and maintain while working with promises.

async functions always return a Promise.
await pauses execution until the Promise is resolved or rejected.
